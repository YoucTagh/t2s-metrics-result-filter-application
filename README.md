# T2S-Metrics Result Filter Application

This project involves consuming the results of running an evaluation in t2s-metrics and creating filters on the evaluation metrics to identify cases that validate the filters.

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. 

Two result files are provided for testing at `./datasets/*`
